# 単体テスト仕様書：SC-03 勤怠閲覧・編集画面（admin）

対象画面：`_pages/02_admin_attendance_edit.py`
確認方法：ブラウザ操作　→　画面表示結果、および保存後のExcelファイル内容を確認する

## 1. ユーザー・対象年月の選択

| No. | 操作手順 | 期待結果 | 結果 |
|---|---|---|---|
| 1-1 | adminでログインし、画面を開く | 対象ユーザー・対象年月のプルダウンが表示され、登録済み一般ユーザーが選択肢に並ぶ（adminアカウント自身は含まれない） | ok |
| 1-2 | 対象ユーザーを選択する | 選択したユーザーの氏名・社員番号・部署名がヘッダーに表示される | ok |
| 1-3 | 一般ユーザーが1人も登録されていない状態で画面を開く | 「対象ユーザーが登録されていません。」と表示され、以降のUIが表示されない | ok |
| 1-4 | 対象ユーザー・対象年月を選び直す | プレビュー表示に切り替わる（編集モードに入っていた場合は自動的に解除される） | ok |

## 2. ロック状態と編集操作の可否（一般ユーザーとの排他性の確認）

| No. | 操作手順 | 期待結果 | 結果 |
|---|---|---|---|
| 2-1 | 未ロックの月・ユーザーを選択する | 「● 未ロック」バッジが表示され、「編集する」ボタンが押せない状態（disabled）になっている | ok |
| 2-2 | 未ロックの月で「編集する」ボタンの下の注意書きを確認する | 「ロックされていないファイルは編集できません。ロック管理画面から先にロックしてください。」と表示される | ok |
| 2-3 | ロック管理画面で対象ユーザー・対象月をロックしたあと、本画面に戻り同じユーザー・月を選択する | 「● ロック中」バッジが表示され、「編集する」ボタンが押せる状態になる | ok |
| 2-4 | ロック中の状態でプレビュー表示を確認する | ロック状態に関わらず、プレビュー内容が問題なく表示される | ok |

## 3. 編集操作（ロック中のファイル）

| No. | 操作手順 | 期待結果 | 結果 |
|---|---|---|---|
| 3-1 | ロック中のユーザー・月で「編集する」を押す | 一般ユーザー画面と同様の編集フォーム（1日1行）が表示される | ok |
| 3-2 | 平日の行に始業・終業時間を入力する | 入力どおりに反映され、赤枠エラーが出ない | ok |
| 3-3 | 全角文字で時刻を入力する | 自動的に半角へ変換される | ok |
| 3-4 | 不正な形式の時刻を入力する | 該当行が赤枠になり、一般ユーザー画面と同様のエラーメッセージが表示される | ok |
| 3-5 | 休暇区分「欠勤」を選択した状態で時刻が入力済みだった場合 | 該当行が赤枠になり、時刻入力を解除するよう促すメッセージが表示される | ok |
| 3-6 | 土日で休暇種類未選択のまま時刻を入力する | 該当行が赤枠になる |
| 3-7 | エラーが残っている状態で「保存する」ボタンの状態を確認する | ボタンが押せない状態になっている |
| 3-8 | エラーを解消し「保存する」を押す | 「保存しました。」と表示され、プレビューへ戻る | ok |
