# 単体テスト仕様書：バリデーション横断シナリオ（VAL-01〜05）

対象画面：`_pages/01_attendance_input.py`（一般ユーザー）、`_pages/02_admin_attendance_edit.py`（admin）
確認方法：ブラウザ操作で編集フォームに入力　→　画面上のリアルタイムエラー表示、および保存可否の結果を確認する

補足：入力パターンは一般ユーザー画面・admin画面のいずれでも同一の見え方になることを想定。特記のない限り両画面共通の確認項目とする。

## 1. VAL-03：休暇区分×時刻入力の矛盾（順方向・逆方向）

| No. | 操作手順 | 期待結果 | 結果 |
|---|---|---|---|
| 1-1 | 休暇種類「有休」を選択後、始業欄に時刻を入力しようとする | 始業欄が入力不可（グレーアウト）になっており、そもそも時刻を打ち込めない | ok |
| 1-2 | 始業「9:00」・終業「18:00」を入力した状態から、休暇種類を「欠勤」に変更する（逆順操作） | 該当行が赤枠になり、「『欠勤』の日には始業・終業時間を入力できません。時刻を未入力に戻してください。」と表示される。この状態のまま「保存する」を押しても保存が実行されない | ok |
| 1-3 | 1-2の状態から始業・終業を空欄に戻す | 赤枠が消え、休暇種類「欠勤」のまま保存できる状態になる | ok |
| 1-4 | 休暇種類「長期連休」「特別休暇」「振替休暇」のそれぞれで、1-2と同様の逆順操作を行う | いずれも同様に赤枠エラーが表示される | ok |
| 1-5 | 休暇種類「午前半休」を選択した状態で時刻を入力する | エラーにならず、時刻入力欄は有効なまま（半休は対象外区分のため） | ok |
| 1-6 | 休暇種類「休日出勤」を選択した状態で時刻を入力する | エラーにならない（対象外区分） | ok |

## 2. VAL-04／VAL-05：土日の時刻入力

| No. | 操作手順 | 期待結果 | 結果 |
|---|---|---|---|
| 2-1 | 土曜日の行で休暇種類を選択しないまま始業時間を入力する | 該当行が赤枠になり、「休日に始業・終業時間が入力されています。」と表示される | ok |

| 2-5 | 平日（月〜金）の行で休暇種類を選択しないまま時刻を入力する | エラーが表示されない（曜日条件に該当しないため） | ok |

## 3. 時刻フォーマットのリアルタイムチェック

| No. | 操作手順 | 期待結果 | 結果 |
|---|---|---|---|
| 3-1 | 始業欄に「9時」と入力する | 該当行が赤枠になり、「始業の形式が不正です。『9:00』のように半角数字とコロンで入力してください。」と表示される | ok |
| 3-2 | 始業欄に「24:00」と入力する | 赤枠エラーが表示される（0〜23時の範囲外） | ok |

| 3-6 | 始業・終業・離業の3欄すべてに不正な形式を入力する | 「始業・終業・離業の形式が不正です。」のように該当する全項目名がまとめて表示される | ok |

## 4. 複数エラーが同時に存在する場合の保存制御

| No. | 操作手順 | 期待結果 | 結果 |
|---|---|---|---|
| 4-1 | 月内の複数日でそれぞれ異なる種類のエラー（VAL-03違反の行、土日エラーの行、形式エラーの行）を作る | それぞれの行が個別に赤枠表示され、画面下部に「赤枠の行にエラーがあります。修正してから保存してください。」と表示される | ok |
| 4-2 | 4-1の状態で「保存する」ボタンを確認する | ボタンが押せない状態になっている | ok |
| 4-3 | エラーのある行を1つずつ修正していく | 修正した行から順に赤枠が消えていき、全て解消すると保存ボタンが押せるようになる | ok |
| 4-4 | 一部のエラーを残したまま保存を試行できないことを確認する（ボタンdisabledの直接確認） | 保存処理自体が実行されず、Excelファイルへの書き込みも発生しない | ok |
