# 単体テスト仕様書：保存後のExcelファイル内容確認（横断）

対象画面：`_pages/01_attendance_input.py`、`_pages/02_admin_attendance_edit.py`
確認方法：画面から保存操作を行った後、OneDrive（疑似ローカル）上のExcelファイルをExcelまたはビューアで直接開いて中身を確認する

## 1. セル位置の確認

| No. | 操作手順 | 期待結果 | 結果 |
|---|---|---|---|
| 1-1 | ある日の休暇種類に「有休」を選択して保存する | `原本`シートの該当日の行のD列に「有休」と入力されている | ok |
| 1-2 | 始業「9:00」・終業「18:00」を入力して保存する | N列に「9:00」、Q列に「18:00」が半角・先頭ゼロなしの文字列（または対応する時刻値）で入力されている | ok |
| 1-3 | 離業時間「12:30」を入力して保存する | AC列に「12:30」が入力されている | ok |
| 1-4 | 自社工数内容に「A社対応」と入力して保存する | AP列に「A社対応」が入力されている | ok |

## 2. 書式の保持

| No. | 操作手順 | 期待結果 | 結果 |
|---|---|---|---|
| 2-1 | 保存前に対象セル周辺の罫線・背景色を記録しておき、値を保存する | 保存後も罫線・背景色が変化していない | ok |
| 2-2 | 保存対象外の行（他の日）のセルを確認する | 値・書式ともに変化していない | ok |
| 2-3 | 保存を複数回（同じ月に対して繰り返し）行う | 繰り返しても書式が徐々に崩れていくことがない | ok |
| 2-4 | F11:G16、F18:H21の範囲（フロント入力対象外セル）を保存前後で確認する | テンプレートのまま変化していない | ok |

## 3. ヘッダーセルの自動設定確認（月次ファイル新規生成時）

| No. | 操作手順 | 期待結果 | 結果 |
|---|---|---|---|
| 3-1 | まだファイルが存在しない月に一般ユーザーが初めてアクセスする | 新規にExcelファイルが生成され、C8セルが対象月の初日（例：2026/06/01）になっている | ok |
| 3-2 | 3-1で生成されたファイルのO5セルを確認する | ログインユーザーの社員番号が入っている | ok |
| 3-3 | 3-1で生成されたファイルのAH4セルを確認する | ユーザーマスタに登録された部署名が入っている | ok |
| 3-4 | 3-1で生成されたファイルのAH5セルを確認する | 「姓　名」の形式（全角スペース区切り）で氏名が入っている | ok |
| 3-5 | 3-1で生成されたファイル名を確認する | 「【会社名】勤務実績管理表_YYYYMM_姓名.xlsx」の形式で、氏名部分にスペースが入っていない | ok |

| 4-2 | 「記入例」シートの内容を確認する | テンプレートの記入例がそのままコピーされている（フロントから編集されていない） | ok |

## 5. 自動計算列の表示確認（プレビュー画面とExcelの整合性）

| No. | 操作手順 | 期待結果 | 結果 |
|---|---|---|---|
| 5-1 | 始業「9:00」・終業「18:00」（休憩1時間）で保存した後、プレビュー画面の実働時間欄を確認する | 「8:00」のように休憩控除後の実働時間が表示される | ok |
| 5-2 | 5-1のファイルをExcelで直接開き、AF列（実働時間）を確認する | Excelを開いて再計算させた場合、プレビューと同じ実働時間が表示される（数式が壊れていない） | ok |
| 5-3 | 保存直後（Excelアプリで一度も開いていない状態）でプレビュー画面を再表示する | 保存前の古いキャッシュ値ではなく、最新の入力内容に基づいた実働時間が表示される | ok |
| 5-4 | 休日出勤の日を保存後、プレビュー画面の休日出勤欄と超勤欄を確認する | 休日出勤欄に実働相当の時間が表示され、超勤欄は空欄（--:--）になっている | ok |

## 6. 月をまたいだファイルの独立性

| No. | 操作手順 | 期待結果 | 結果 |
|---|---|---|---|

| 6-2 | 同じ月について、異なる2人のユーザーがそれぞれ保存する | 互いのExcelファイルは別ファイルとして保存され、内容が混在しない | ok |
