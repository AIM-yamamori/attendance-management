# 単体テスト仕様書：月次ファイル自動生成・フォルダ作成（横断）

対象画面：`_pages/01_attendance_input.py`、`_pages/02_admin_attendance_edit.py`
確認方法：ブラウザ操作で対象月へ初めてアクセスし、OneDrive（疑似ローカル）上のフォルダ・ファイル構成を確認する

## 1. 初回アクセス時の自動生成

| No. | 操作手順 | 期待結果 | 結果 |
|---|---|---|---|
| 1-1 | まだ誰もアクセスしたことのない月（対象月フォルダが存在しない）に、一般ユーザーが初めてアクセスする | エラーにならず、空のプレビュー（またはロード後の編集可能な画面）が表示される | ok |
| 1-2 | 1-1の直後、OneDrive（疑似ローカル）のディレクトリ構成を確認する | 対象月名（YYYYMM）のフォルダが作成されており、その中にログインユーザー名を含むExcelファイルが1つ生成されている | ok |
| 1-3 | 同じ月に再度アクセスする（画面を再読み込みする） | 新しいファイルが再生成されず、既存のファイルがそのまま読み込まれる（内容が初期化されない） | ok |

## 2. 複数ユーザーの同一月フォルダ共有

| No. | 操作手順 | 期待結果 | 結果 |
|---|---|---|---|
| 2-1 | ユーザーAが初めてある月にアクセスし、フォルダとファイルを生成させる | 月フォルダが作成される | ok |
| 2-2 | 続けてユーザーBが同じ月に初めてアクセスする | 新しいフォルダは作られず（既存の月フォルダがそのまま使われ）、ユーザーB用のExcelファイルのみがそのフォルダ内に追加生成される | ok |
| 2-3 | 2-1・2-2の後、月フォルダの中身を確認する | ユーザーAとユーザーBそれぞれのExcelファイルが1つずつ、合計2ファイル存在する | ok |

## 3. adminによるアクセスでの生成

| No. | 操作手順 | 期待結果 | 結果 |
|---|---|---|---|
| 3-1 | 一般ユーザーが一度もアクセスしていない月・ユーザーの組み合わせを、adminが勤怠閲覧・編集画面で選択する | エラーにならず、その場でファイルが新規生成されてプレビューが表示される | ok |
| 3-2 | 3-1の後、OneDriveの当該フォルダを確認する | 対象ユーザーのExcelファイルが生成されている | ok |

## 4. テンプレートファイル不在時の挙動

| No. | 操作手順 | 期待結果 | 結果 |
|---|---|---|---|
| 4-1 | OneDriveのルート直下にテンプレートファイルが存在しない状態で、未生成の月にアクセスする | 画面上にエラーメッセージが表示され、勤怠データの入力画面には進めない | ok |

## 5. 記入例シートのヘルプ表示との整合性

| No. | 操作手順 | 期待結果 | 結果 |
|---|---|---|---|
| 5-1 | 新規生成されたファイルに対して「ヘルプ」ボタンを押す | テンプレートからコピーされた記入例シートの内容が正しく表示される | ok |
