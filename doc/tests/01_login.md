# 単体テスト仕様書：SC-01 ログイン画面

対象画面：`app.py`
確認方法：ブラウザ操作　→　画面表示・遷移結果を確認

## 1. ログイン成功

| No. | 操作手順 | 期待結果（画面上に見える内容） | 結果 |
|---|---|---|---|
| 1-1 | ログイン画面で、登録済みの一般ユーザーの社員番号とパスワードを入力し「ログイン」を押す | エラーメッセージが表示されず、勤怠入力・閲覧画面（一般ユーザー用サイドバーメニュー）に遷移する | ok |
| 1-2 | 登録済みadminアカウント（ID: admin）と正しいパスワードでログインする | 勤怠閲覧・編集画面（admin用サイドバーメニュー：勤怠閲覧・編集／PDF出力／ロック管理／ユーザー管理／パスワード変更）に遷移する | ok |
| 1-3 | ログイン後、サイドバーの表示内容を確認する（一般ユーザー） | 氏名・社員番号・「一般ユーザー」ラベルが表示され、「ログアウト」ボタンが表示される | ok |
| 1-4 | ログイン後、サイドバーの表示内容を確認する（admin） | 「管理者」のみ表示され、氏名や社員番号は表示されない | ok |

## 2. ログイン失敗

| No. | 操作手順 | 期待結果 | 結果 |
|---|---|---|---|
| 2-1 | 存在しない社員番号でログインを試みる | 「IDまたはパスワードが正しくありません」と表示され、画面遷移しない | ok |
| 2-2 | 登録済み社員番号に誤ったパスワードでログインを試みる | 「IDまたはパスワードが正しくありません」と表示され、画面遷移しない | ok |
| 2-3 | 2-1と2-2で表示されるメッセージ文言が同一であることを確認する | 両ケースでメッセージが一言一句同じ（IDの存在有無が区別できない） | ok |
| 2-4 | 社員番号・パスワードを空欄のままログインを押す | 「IDまたはパスワードが正しくありません」等のエラーが表示され、遷移しない | ok |

## 3. サイドバーのメニュー出し分け（未ログイン時・権限別）

| No. | 操作手順 | 期待結果 | 結果 |
|---|---|---|---|
| 3-1 | ブラウザでアプリへ初回アクセスする（未ログイン状態） | ログインフォームのみが表示され、サイドバーに業務メニュー（勤怠入力等）が一切表示されない | ok |
| 3-2 | 一般ユーザーでログイン後、サイドバーのメニュー項目を確認する | 「勤怠入力・閲覧」「パスワード変更」のみが表示され、admin専用メニュー（PDF出力等）は表示されない | ok |
| 3-3 | adminでログイン後、サイドバーのメニュー項目を確認する | 「勤怠閲覧・編集」「PDF出力」「ロック管理」「ユーザー管理」「パスワード変更」が表示され、「勤怠入力・閲覧」は表示されない | ok |
| 3-4 | 一般ユーザーでログイン中に、admin専用画面のURLを直接指定してアクセスする | 「このページを表示する権限がありません」と表示され、画面の内容が表示されない | ok |
| 3-5 | adminでログイン中に、一般ユーザー専用の勤怠入力画面のURLを直接指定してアクセスする | 「adminアカウントは勤怠データを持ちません。『勤怠閲覧・編集』画面をご利用ください。」と案内表示され、画面の内容が表示されない | ok |

## 4. ログアウト

| No. | 操作手順 | 期待結果 | 結果 |
|---|---|---|---|
| 4-1 | ログイン中に「ログアウト」ボタンを押す | ログイン画面に戻り、サイドバーのメニューが再び表示されなくなる | ok |
| 4-2 | ログアウト後、ブラウザの「戻る」等で元の業務画面に戻ろうとする | ログイン画面が表示される（セッションが破棄されており業務画面は表示されない） | ok |
| 4-3 | admin状態でログアウトし、続けて一般ユーザーとして再ログインする | サイドバーの残像（adminメニュー）が表示されず、一般ユーザー用メニューのみが正しく表示される | ok |

## 5. 初回起動（adminアカウントの自動作成）

| No. | 操作手順 | 期待結果 | 結果 |
|---|---|---|---|
| 5-1 | データベースが空の状態でアプリを初めて起動し、ID「admin」・初期パスワードでログインする | ログインに成功し、admin用画面に遷移する（初回起動時にadminアカウントが自動作成されていることが確認できる） | ok |
