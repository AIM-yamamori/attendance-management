# 単体テスト仕様書：SC-07 パスワード変更画面

対象画面：`_pages/06_password_change.py`
確認方法：ブラウザ操作　→　画面表示結果、および変更後のログイン挙動を確認する

## 1. 画面表示

| No. | 操作手順 | 期待結果 | 結果 |
|---|---|---|---|
| 1-1 | 一般ユーザーでログインし、パスワード変更画面を開く | 「（氏名） さんのパスワードを変更します。」と表示され、現在のパスワード・新しいパスワード・確認用の3つの入力欄が表示される | ok |
| 1-2 | adminでログインし、パスワード変更画面を開く | 同様のフォームが表示される（一般ユーザー・admin共通画面） | ok |

## 2. 正常系

| No. | 操作手順 | 期待結果 | 結果 |
|---|---|---|---|
| 2-1 | 現在のパスワードを正しく入力し、新しいパスワード「NewPass12」を2つの新パスワード欄に一致させて入力し「変更する」を押す | 「パスワードを変更しました」と表示される | ok |
| 2-2 | 2-1の後、ログアウトして旧パスワードでログインを試みる | ログインに失敗する | ok |
| 2-3 | 2-1の後、ログアウトして新パスワード「NewPass12」でログインを試みる | ログインに成功する | ok |
| 2-4 | adminアカウントで同様にパスワード変更を行う | admin自身のパスワードも同様に変更でき、新パスワードでログインできる | ok |

## 3. 異常系：現在のパスワード不一致

| No. | 操作手順 | 期待結果 | 結果 |
|---|---|---|---|
| 3-1 | 現在のパスワード欄に誤った値を入力し、新パスワードは正しく入力して「変更する」を押す | 「現在のパスワードが正しくありません」と表示され、パスワードは変更されない | ok |
| 3-2 | 3-1の後、旧パスワードでログインできることを確認する | 変更前のパスワードでログインに成功する（変更が実行されていないことの確認） | ok |

## 4. 異常系：新パスワード確認不一致

| No. | 操作手順 | 期待結果 | 結果 |
|---|---|---|---|
| 4-1 | 「新しいパスワード」と「新しいパスワード（確認）」に異なる値を入力して「変更する」を押す | 「新しいパスワードが一致しません」と表示され、変更されない | ok |

## 5. 異常系：新パスワードのポリシー違反

| No. | 操作手順 | 期待結果 | 結果 |
|---|---|---|---|
| 5-1 | 現在のパスワードは正しく入力し、新パスワードに7文字の値を入力する（確認欄も同じ値） | ポリシー違反のエラーメッセージが表示され、変更されない | ok |
| 5-2 | 新パスワードに英小文字のみの値を入力する | 「2種類以上」等のポリシー違反エラーが表示され、変更されない | ok |
| 5-3 | 新パスワードに全角文字を含む値を入力する | 「使用できない文字が含まれています」等のエラーが表示され、変更されない | ok |
| 5-4 | 5-1〜5-3のいずれの場合も、変更前のパスワードでログインできることを確認する | ログインに成功する（変更が実行されていない） | ok |

## 6. 境界値

| No. | 操作手順 | 期待結果 | 結果 |
|---|---|---|---|
| 6-1 | 新パスワードとして現在のパスワードと同じ値を入力して変更する | ポリシーを満たしていれば「パスワードを変更しました」と表示され、変更処理自体は成功する（同一値の禁止は行われない） | ok |
| 6-2 | 新パスワードにちょうど8文字・英大小混在の値を入力する | 正常に変更できる | ok |
