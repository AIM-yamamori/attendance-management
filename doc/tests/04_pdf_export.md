# 単体テスト仕様書：SC-04 PDF出力画面

対象画面：`_pages/03_admin_pdf_export.py`
確認方法：ブラウザ操作　→　ダウンロードされたPDF/ZIPファイルの中身を確認する

## 1. 画面表示・ユーザー一覧

| No. | 操作手順 | 期待結果 | 結果 |
|---|---|---|---|
| 1-1 | adminでログインし、PDF出力画面を開く | 対象年月プルダウンと、登録済み一般ユーザーのチェックボックス一覧が表示される | ok |
| 1-2 | 一般ユーザーが1人も登録されていない状態で画面を開く | 「対象ユーザーが登録されていません。」と表示され、以降のUIが表示されない | ok |
| 1-3 | ユーザーを1人も選択していない状態で画面下部を確認する | 「対象ユーザーを1名以上選択してください。」と表示され、「PDF生成」ボタンが押せない | ok |

## 2. 「すべて選択」チェックボックス

| No. | 操作手順 | 期待結果 | 結果 |
|---|---|---|---|
| 2-1 | 「すべて選択」にチェックを入れる | 全ユーザーのチェックボックスが一括でONになる | ok |
| 2-2 | 「すべて選択」のチェックを外す | 全ユーザーのチェックボックスが一括でOFFになる | ok |
| 2-3 | 全ユーザーを個別に手動でチェックする | 「すべて選択」が自動的にON表示になる | ok |
| 2-4 | 全ユーザーチェック済みの状態から1人だけチェックを外す | 「すべて選択」が自動的にOFF表示になる | ok |

## 3. 対象年月の切り替え

| No. | 操作手順 | 期待結果 | 結果 |
|---|---|---|---|
| 3-1 | ユーザーを選択した状態で対象年月を変更する | 選択していたユーザーのチェックがすべて解除される（月ごとに選び直しになる） | ok |
| 3-2 | 3-1の後、以前生成したダウンロードボタンの表示を確認する | ダウンロードボタンが消える（前回生成分がクリアされる） | ok |

## 4. 単一ユーザーのPDF生成

| No. | 操作手順 | 期待結果 | 結果 |
|---|---|---|---|
| 4-1 | ユーザーを1名だけ選択し「PDF生成」を押す | 生成完了後、「PDFをダウンロード」ボタンが表示される | ok |
| 4-2 | 「PDFをダウンロード」を押し、ファイルを開く | 拡張子が.pdfで、ファイル名が「勤務実績管理表_YYYYMM_姓名.pdf」の形式になっている | ok |
| 4-3 | ダウンロードしたPDFの内容を確認する | 対象ユーザー・対象月の「原本」シートの内容（J1:AQ50相当の範囲）がA4縦1ページに収まって印字されている | ok |
| 4-4 | PDFの曜日列を確認する | 日本語（月〜日）で正しく表示されている（英語表記になっていない） | ok |
| 4-5 | PDFに「記入例」シートの内容が含まれていないことを確認する | 記入例シートの内容は出力されない（原本シートのみ） | ok |

## 5. 複数ユーザーのZIP生成

| No. | 操作手順 | 期待結果 | 結果 |
|---|---|---|---|
| 5-1 | ユーザーを2名以上選択し「PDF生成」を押す | 生成完了後、「ZIPをダウンロード」ボタンが表示される | ok |
| 5-2 | ZIPファイル名を確認する | 「勤務実績管理表_YYYYMM.zip」の形式になっている | ok |
| 5-3 | ZIPを解凍し、中身のファイル数を確認する | 選択した人数分のPDFファイルが個別に含まれている（1ユーザー1ファイル、結合されていない） | ok |
| 5-4 | 解凍した各PDFのファイル名を確認する | それぞれ対象ユーザーの氏名を含む正しいファイル名になっている | ok |
| 5-5 | 解凍した各PDFの内容を確認する | それぞれ対応するユーザー本人の勤怠内容が印字されている（他ユーザーの内容と混在していない） | ok |
