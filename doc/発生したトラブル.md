# 発生したトラブル

## 1. Entra ID（Azure Entra ID）が未設定のため、システムが OneDrive にアクセスできない

### 事象
- システムが OneDrive 上の勤怠 Excel にアクセスできず、読み書き処理が失敗する
- 認証エラー（invalid_client / unauthorized_client など）が発生する
- Graph API の呼び出しがすべて拒否される

### 原因
OneDrive にアクセスするために必要な Entra ID アプリ登録情報が存在しないため。

不足している項目：
- クライアントID（Application ID）
- テナントID（Directory ID）
- クライアントシークレット値（Client Secret Value）
   - ※「値（Value）」が .env に必要
   - ※「説明（Description）」ではない

これらが揃わないと、Graph API による OneDrive へのアクセスは認証できない。

### 解決方法
1. 管理者に Entra ID アプリ登録を依頼する
   - 一般ユーザーではアプリ登録ができないため、
   - Microsoft 365 テナント管理者に以下の作業を依頼する必要がある。
2. 発行された値を `.env` に設定する
   - 管理者から受け取った以下の値を、システム側の `.env` に設定する。
   - ※ クライアントシークレットは「Value」だけが必要  
   - ※ Value は作成時に一度しか表示されないため、必ず控えること
3. Graph API の認証が成功するかテストする
   - 最低限、以下の API が成功すれば認証は正常。
     - GET https://graph.microsoft.com/v1.0/me/drive/root
     - GET https://graph.microsoft.com/v1.0/users/{user-id}/drive/root
     - Excel ファイルの読み取り API
4. OneDrive の共有リンク方式を使っている場合の注意
   - 共有URLだけでは 読み取りはできるが書き込みはできない。
   - 勤怠Excelを編集するシステムでは必ず Graph API が必要。

## 2. OneDrive 共有URL解決が 401（spException）で失敗する問題：アプリケーション許可不足が原因

### 事象
- Microsoft Graph API を使用して OneDrive の共有URLを解決しようとした際に  
以下のエラーが発生した。
```
OneDriveError: 共有URLの解決に失敗しました（401）
{
"error": {
"code": "generalException",
"innerError": {
"code": "spException",
"innerError": { "code": "other" }
},
"message": "General exception while processing"
}
}
```

### 原因
- **アプリが持っている権限が「委任された許可（Delegated）」のみで、  
必要な「アプリケーションの許可（Application permissions）」が付与されていなかったため。**
- OneDrive の共有URLを解決するには **Files.ReadWrite.All（アプリケーションの許可）** が必須

### 解決方法
1. Azure Portal を開く  
   - https://portal.azure.com/
2. 左メニュー **Microsoft Entra ID** を選択
3. **アプリの登録 → 該当アプリを選択**
4. 左メニュー **API のアクセス許可** を開く
5. **「アクセス許可の追加」** をクリック  
→ Microsoft Graph  
→ **「アプリケーションの許可」** を選択  
→ **Files.ReadWrite.All** にチェック  
→ 追加
1. 画面上部の **「（テナント名）に管理者の同意を与えます」** をクリックして同意を付与
