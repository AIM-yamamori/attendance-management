## 3. Google Cloud Runでデプロイ

サービス名は以下

```
attendance-management
```

今回はGoogle Cloud BuildでGitHubリポジトリからビルド

Cloud Runで以下を設定
- コンテナ設定（メモリ、CPUなど）
  - メモリ: 512MiB（足りなければ増やす）
  - CPU: 1
- 環境変数（.env）
- サービスのスケーリング
  - インスタンスの最小数: 0
  - インスタンスの最大数: 1
- 課金
  - リクエストベース
